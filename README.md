# Blade Painel — atualizações

Aqui ficam só os **instaladores** do Blade Painel, o programa de administração da equipe do Blade of Steel. O código fica em outro lugar.

- O próprio Blade Painel procura a versão nova aqui e se atualiza sozinho, conferindo o SHA-256 do arquivo antes de instalar.
- Para instalar à mão: baixe o `BladePainel-Setup-<versão>.exe` da última release.
- O programa só funciona com um usuário de staff do Blade of Steel.
